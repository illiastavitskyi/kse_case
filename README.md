# Прогноз початку повітряної тривоги по областях України

Для кожної області: ймовірність, що тривога **почнеться** в найближчу годину `[T, T+1h)`. Модель — LightGBM, навчена один раз; сервіс лише перераховує ймовірності на свіжих даних.

## Дані
- Офіційний датасет (`official_data_uk.csv`) до 2026-09-07 08:28 (Київ) + волонтерський (`volunteer_data_uk.csv`) після. Джерело: [Vadimkin/ukrainian-air-raid-sirens-dataset](https://github.com/Vadimkin/ukrainian-air-raid-sirens-dataset).
- Часи UTC → Europe/Kyiv. Рівень — область (Київ і Київська окремо), Луганська виключена. Інтервали злиті, довші за 72 год обрізані.
- Розрив: офіційне визначення — «тривога в будь-якому районі», волонтерське — на рівні області.


## Результат (test 26.09–10.10, база 0.232)
PR-AUC 0.505 (baseline `onset_rate_30d` 0.491), Brier 0.1482 (0.1497), ROC-AUC 0.768.
Поріг «тривога очікується» = 0.26: recall ≈ 0.68, precision ≈ 0.41, FPR ≈ 30%.
Перевага над простим baseline мала.

## Запуск
Сирі CSV не в репо. Завантаж у корінь проєкту (офіційний файл не змінюється, волонтерський сервіс оновлює сам):
```
B=https://raw.githubusercontent.com/Vadimkin/ukrainian-air-raid-sirens-dataset/main/datasets
pip install -r requirements.txt
python main.py splice          # навчання (потрібні CSV поруч)
uvicorn app:app                # сторінка http://127.0.0.1:8000/alerts
pytest -q
```
Сервіс при старті і щогодини (ХХ:02) завантажує свіжий `volunteer_data_uk.csv` і перераховує прогноз; ваги не змінюються. Джерело оновлюється раз на добу, тому сторінка показує відставання даних.

## Структура
`main.py` — дані, ознаки, навчання, звіти · `service.py` — оновлення даних і прогноз · `app.py` + `templates/alerts.html` — сторінка `/alerts` · `test_leakage.py` — тести · `artifacts/` — моделі · `reports/` — логи запусків.
